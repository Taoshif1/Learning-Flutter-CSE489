# Task 01 — Android Studio and Dart Warm-up

This project covers the first Dart console exercises in the CSE 489 introductory lab manual.

## Concepts
- Dart application's `main()` entry point
- Single-line comments and `print()`
- Integer variables and arithmetic
- Normal division (`/`) and integer division (`~/`)

## Current implementation
The original greeting example is retained as a commented section. The active program demonstrates the expanded arithmetic challenge using 12 and 5.

Expected output:

```text
Sum: 17
Difference: 7
Multiplication: 60
Division: 2.4
Integer Division: 2
```

## Run

```powershell
dart pub get
dart run bin\task1.dart
```
