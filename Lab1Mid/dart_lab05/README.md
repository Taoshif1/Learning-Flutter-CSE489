# Task 05 — Loops, break, and continue

This project practises repeated execution and loop control in Dart.

## Concepts
- `for` and `while` loops
- `do-while` loops
- Iterating over a list with `for-in`
- `break` to leave a loop
- `continue` to skip the current iteration
- Accumulating a running sum

## Current implementation
The multiplication-table example, while-loop sum, break/continue example, for-in course list, and while-based challenge are retained as commented examples.

The active program is the do-while version of the challenge. It reads integers, adds positive values to a running total, and stops when a negative number is entered. Zero is not added, but the loop continues because its condition is `number >= 0`.

## Run

```powershell
dart pub get
dart run bin\dart_lab05.dart
```

Run from an interactive terminal and enter several positive values followed by a negative value.
