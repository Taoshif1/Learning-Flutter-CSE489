# Task 03 — Operators and Null Safety

This project practises arithmetic, comparison, logical, conditional, and null-aware operators in Dart.

## Concepts
- Arithmetic: `+`, `-`, `*`, `/`, `~/`, and `%`
- Comparison and logical expressions
- Conditional operator
- Nullable types such as `int?` and `double?`
- Null fallback with `??`
- Null-aware assignment with `??=`

## Current implementation
The arithmetic/operator example and nullable score example are retained as commented code. The active challenge declares a nullable temperature, prints “Not provided” while it is null, assigns 28.5, and prints the value.

## Run

```powershell
dart pub get
dart run bin\dart_lab03.dart
```
